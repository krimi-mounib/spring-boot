# AutoLoc — Guide principal

Le guide complet pour lancer et tester les Ateliers 5 et 6 se trouve dans [`README-DEMARRAGE-TESTS.md`](README-DEMARRAGE-TESTS.md).

- Projet Maven : ouvrir ce dossier dans IntelliJ IDEA.
- Profil rapide : `mvn spring-boot:run -Dspring-boot.run.profiles=demo` (H2 en mémoire + données de démonstration).
- Swagger : http://localhost:8081/api/swagger-ui.html
- Collection Postman : `postman/AutoLoc-Ateliers-5-6.postman_collection.json`.
- Rapport final : `docs/Atelier5_Atelier6_Rapport_Final.docx`.
